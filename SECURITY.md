## Supported versions

Only the latest release receives fixes.

## Reporting a vulnerability

> [!WARNING]
> Please do **not** open a public issue for security problems.

1. Use GitHub's private vulnerability reporting for this repository (Security tab, "Report a vulnerability"), or
2. Email yash92726@gmail.com with the subject "Battery Stats security".

Include the app version, Android version and device, steps to reproduce, and the impact you expect. You will get an acknowledgement as soon as possible, and fixes will be released with a note in the changelog.

## Scope

In scope: the app and the released APK files. Out of scope: vulnerabilities in third-party libraries that are already public, and issues that need a rooted or already-compromised device.
